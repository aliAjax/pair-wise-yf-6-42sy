# 家庭药箱

端口规划：`5114`

```bash
npm install
npm run dev
```

本地家庭药箱，避免重复买药：

- 每种药记录名称、规格、用途、位置、总数、已用数、开封日期，服药时扣减，余量不足或开封满三个月则不记服药。
- 同名同规格再登记时并入原药盒：数量累加，开封日期和服药记录沿用原盒。
- 开封满三个月或数量用完显示「待补」（不再记账），服药历史始终保留可查看。
- 列表可按位置、用途、待补状态筛选，待补优先排序；数据存于 localStorage，首次打开自动备好示例药箱。

业务文件：

- `src/rules.js`：判断与规则（余量、待补、扣减、合并、筛选排序）
- `src/storage.js`：存档（localStorage 读写、示例数据；旧维修数据 `zfl-14-repairs` 不读取）
- `src/page.js`：页面渲染与交互
